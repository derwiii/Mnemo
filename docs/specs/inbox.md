# Mnemo: трей, быстрый ввод и входящие

Обновлено 19 ноября 2026. Действующие требования. Общая палитра и оформление определены в FR-Q13 и спецификации дизайна.

Этот документ определяет заготовки входящих слов и интеграцию с рабочим столом (FR-Q1–FR-Q14). [Карта спецификаций](../../spec.md).

## 1. InboxEntry

Отдельная сущность, не Card и не особый тип Deck. Хранится в той же локальной SQLite-базе, но не имеет CardState или ReviewLog и не требует привязки к колоде.

| Поле | Тип | Правило |
|---|---|---|
| id | string | уникальный идентификатор |
| front | string | обязательное слово / фраза, ограничения длины как у Card.front |
| front_key | string | ключ дубликата: casefold и схлопывание пробелов, как [FR-C6](cards.md#4-управление-карточками) |
| translations | string[] (0..10) | переводы необязательны; пустые строки отбрасываются |
| context | string | необязательный исходный контекст |
| created_at / updated_at | datetime | дата добавления и последнего сохранения |

Заготовки не включаются в число учебных карточек, очереди любых сессий, статистику повторений или текущий JSON-импорт/экспорт колод. Настройки автозапуска и горячей клавиши сохраняются локально между запусками. Новый формат хранения добавляется миграцией без изменения существующих карточек и прогресса.

## 2. Поведение

Базовые требования реализованы в v0.20; уточнения взаимодействия и оформления реализованы в v0.21. Они уточняют прежнее поведение закрытия окна. Система повторений не меняется.

- FR-Q1. Приложение поддерживает работу в системном трее Windows. Закрытие основного окна скрывает его в трей, не завершает процесс и не завершает текущую сессию. Подтверждённые основные попытки остаются в БД, свободные результаты — только в памяти текущего прохода; скрытие само по себе не записывает попыток. Одинарный щелчок по значку открывает пустое быстрое добавление, двойной — основное окно. Одинарное действие откладывается на системный интервал двойного щелчка: двойной щелчок не должен одновременно открывать быстрый ввод. Правое нажатие открывает меню: «Добавить слово», «Входящие (N)», «Открыть Mnemo», «Выйти». Последнее действие полностью завершает процесс без записи неподтверждённого ответа. Если трей недоступен, основное окно остаётся доступным: скрытие без возможности восстановления недопустимо.
- FR-Q2. Автозапуск при входе пользователя в Windows включается отдельной настройкой и по умолчанию выключен. Автоматический запуск открывает только трей; обычный ручной запуск открывает основное окно. Повторный запуск не создаёт второй работающий экземпляр, а открывает основной интерфейс существующего. Ошибка изменения автозапуска отображается пользователю, настройка не должна показывать несуществующий успех.
- FR-Q3. Глобальная горячая клавиша по умолчанию — Ctrl+Alt+M; пользователь может изменить её в настройках. Сочетание работает и при скрытом основном окне. При конфликте регистрации показывается понятная ошибка; добавление через трей остаётся доступным.
- FR-Q4. Пользователь сам копирует текст обычным Ctrl+C. Горячая клавиша однократно читает текущий текст буфера и открывает быстрое добавление с этим текстом целиком; автоматического выделения последнего слова нет. При пустом, недоступном или нетекстовом буфере открывается пустая форма. Приложение не наблюдает за буфером постоянно и не имитирует копирование выделения в других программах. Слишком длинный текст не обрезается молча: применяется явная валидация длины.
- FR-Q5. Компактное окно содержит «Слово или фраза», необязательные «Переводы» (до 10), «Сохранить» и «Отмена». Выбора колоды нет. «Добавить слово» через меню трея открывает пустую форму. Внутри быстрого окна есть переходы «Входящие (N)» и «Открыть Mnemo»; переходы не сохраняют и не уничтожают незавершённый ввод. Повторный вызов уже открытого окна поднимает его, сохраняя текущий ввод, без перезаписи текстом буфера.
- FR-Q6. Сохранение требует непустого слова и допустимых длин/числа переводов. Любая запись из быстрого окна сохраняется только во входящие, включая запись с заполненными переводами. При успешной записи окно закрывается. При ошибке форма и введённые данные остаются для исправления или повторной попытки; ложное сообщение об успехе не показывается. Отмена не сохраняет данные.
- FR-Q7. Дубликат во входящих определяется по front_key среди всех заготовок, независимо от переводов. При повторном сохранении того же слова новая запись не создаётся: открывается существующая заготовка во входящих, её переводы и контекст не перезаписываются. Разные значения слова можно оформить при разборе.
- FR-Q8. «Входящие» — отдельный экран основного приложения с собственным счётчиком заготовок рядом с доступом к колодам. Список показывает слово, контекст (если есть) и дату добавления. Выбор записи открывает поля слова, переводов и контекста; можно сохранить изменения заготовки или удалить её. Учебных оценок и расписания у заготовки нет. Кнопка входящих находится в общем верхнем ряду главного экрана рядом со статистикой, импортом и созданием колоды; отдельная строка под шапкой убирается. Настройки автозапуска и горячей клавиши доступны через шестерёнку в заголовке входящих, а не на главном экране. Общий раздел настроек пока не вводится.
- FR-Q9. Из выбранной заготовки пользователь явно создаёт карточку: дополняет переводами, выбирает существующую колоду и нажимает «Создать карточку». Действует обычная валидация Card, включая обязательный минимум одного перевода. При совпадении слова в целевой колоде действует предупреждение и явное подтверждение FR-C6; автоматического создания дубликата нет. Контекст предлагается сохранить как пример, без выдуманного перевода примера. Создание карточки с начальным CardState и удаление заготовки выполняются одной транзакцией. При отмене или ошибке заготовка не удаляется и частично созданная карточка не остаётся. Повторное выполнение после успешного создания не должно создавать ещё одну карточку из той же заготовки.
- FR-Q10. API, автоматический перевод, извлечение слов из файлов и автоматическое создание карточек не входят в этот этап. Необязательные переводы и контекст в заготовке позволяют добавить эти возможности позже. Провайдер, системный промпт и правила автосоздания пока не согласованы.
- FR-Q11. В покое приложение ожидает события без постоянного опроса буфера, сетевых запросов и ненужных анимаций скрытых окон. После реализации измеряются потребление процессора и памяти в трее, после запуска и после серии быстрых добавлений; нулевая нагрузка или конкретный объём памяти заранее не обещаются.
- FR-Q12. Быстрое окно располагается в правом нижнем углу доступной рабочей области с отступом от краёв и без перекрытия панели задач. При горячей клавише используется монитор с указателем мыши, при вызове из трея — монитор со значком трея (при недоступной геометрии — монитор указателя). Позиция рассчитывается после определения размера окна; учитываются несколько мониторов и масштабирование. Повторный вызов поднимает то же окно и при необходимости перемещает его на монитор вызова, сохраняя ввод. Уход фокуса не закрывает форму и не уничтожает данные. Нет модального затемнения экрана; обязательная полупрозрачность не вводится.
- FR-Q13. Быстрое окно и входящие используют оформление Mnemo «Мягкий фокус»: поверхности и акцент выбранной пользователем палитры (по умолчанию «Мягкая медь»), Manrope, контурный мотив карточек и ясную иерархию заголовков и второстепенного текста. Смена схемы сразу обновляет оба окна без потери черновика; крупная обложка главной в компактные формы не переносится. Компактные поля, список и детали заготовки визуально сгруппированы; сохранение и создание карточки имеют различимый основной акцент. Список показывает выбранную запись, контекст и дату, а детали — отдельные блоки слова, переводов, контекста и создания карточки. Системные светлые поверхности недопустимы. При минимальном размере основного окна элементы не перекрываются, детали прокручиваются, а действия верхней навигации и встроенные кнопки окна остаются доступны.
- FR-Q14. Основное окно и быстрый ввод — независимые окна одного процесса. Быстрый ввод не является дочерним/владельческим окном основного и не получает отдельной кнопки на панели задач. Сворачивание, восстановление или закрытие основного окна в трей не сворачивает и не закрывает быстрый ввод. Esc, крестик и «Отмена» в быстром вводе закрывают только эту форму, без сохранения слова и без изменения состояния основного окна. Переходы в основное окно/входящие не уничтожают черновик, повторная горячая клавиша поднимает тот же быстрый ввод, в том числе если он был свёрнут. Постоянное положение поверх всех приложений не вводится. «Выйти» из трея закрывает оба окна и завершает процесс; отложенные вызовы быстрого ввода при выходе отменяются.

## 3. Критерии приёмки
- При одновременно открытых окнах сворачивание/восстановление главного окна и его закрытие в трей не меняют видимость и ввод быстрого окна. Esc в быстром окне закрывает только его, не добавляя слово и не закрывая основное окно.
- Быстрый ввод не имеет отдельной кнопки на панели задач; системная проверка Windows подтверждает отсутствие связи владельца с главным окном. Повторный вызов поднимает существующую форму без потери черновика. Полный выход закрывает оба окна.
- Одинарный щелчок открывает только быстрое окно, двойной — только основное; завершающий сигнал одинарного щелчка после двойного не вызывает быстрый ввод.
- Быстрое окно появляется справа внизу рабочей области выбранного монитора, не перекрывает панель задач. Повторный вызов и потеря фокуса сохраняют черновик; переходы в основное окно и входящие не сохраняют черновик автоматически.
- На главной входящие находятся в общей шапке; там же есть отдельные настройки оформления. Шестерёнка входящих открывает настройки горячей клавиши и автозапуска. Оформление проверяется на обычном и минимальном размерах окна.
- При выключенном автозапуске приложение не добавляется в автозапуск; включение и выключение настройки сохраняются и реально меняют запуск при входе. Автоматический запуск не раскрывает основное окно.
- Закрытие основного окна оставляет значок и работоспособную горячую клавишу; «Открыть Mnemo» восстанавливает окно, «Выйти» завершает процесс. Повторный запуск не оставляет второй экземпляр. Недоступный трей не приводит к невидимому недоступному приложению.
- Текст после Ctrl+C попадает в быстрое окно целиком; пустой/нетекстовый буфер не вызывает ошибку. Повторный вызов не затирает начатый ввод. Конфликт горячей клавиши сообщается, меню трея продолжает работать.
- Слово без перевода и слово с переводами сохраняются во входящие, переживают перезапуск и не появляются ни в обычной, ни в свободной учебной очереди. Учебная статистика от такого сохранения не меняется.
- Пустое слово, превышение длины или более 10 переводов не сохраняются; отмена не создаёт записи, ошибка записи не закрывает форму.
- Повторное добавление того же слова с отличиями регистра/пробелов открывает существующую заготовку и сохраняет её прежние данные; число входящих не растёт.
- После успешного создания карточки из заготовки существует одна карточка с обычным начальным состоянием, а заготовка удалена. Без перевода, при отмене подтверждения дубликата и при сбое транзакции заготовка остаётся; частичного переноса нет.

## 4. Компоновка

«Входящие (N)» размещены в общем верхнем ряду главного экрана со статистикой, импортом и созданием колоды. Настройки горячей клавиши и автозапуска перенесены в заголовок входящих. Это список заготовок, не колода. Список и редактор деталей оформлены отдельными поверхностями выбранной палитры с акцентным выделением; есть фирменный мотив карточек, счётчик, второстепенные контекст и дата. Быстрое окно шириной около 440 логических пикселей находится справа внизу рабочей области, содержит компактные поля слова и переводов, сохранение/отмену и переходы во входящие и основное окно. Не затемняет рабочий стол, не закрывается от потери фокуса. Детали и выбор колоды остаются на экране входящих. Поведение — FR-Q1–FR-Q14; оформление соответствует [дизайну «Мягкий фокус»](design.md).
