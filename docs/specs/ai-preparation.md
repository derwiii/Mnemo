# Mnemo: подготовка карточек через ИИ

Обновлено 16 ноября 2026. Здесь собраны действующие требования к подготовке учебного материала. [Карта спецификаций](../../spec.md).

## 1. Граница функции

Приложение копирует единый [рабочий промпт](../../src/mnemo/resources/ai_prompt.txt) из диалога импорта. Пользователь запускает модель снаружи и импортирует результат. Сетевых запросов, автоматического перевода входящих и двух отдельных модельных вызовов в Mnemo нет.

Рабочий ресурс содержит точный текст для внешней модели; этот документ задаёт требования к нему. Черновики и отчёты не заменяют эти требования. При изменении правил обновляются спецификация и ресурс; исторические результаты прогонов не переписываются.

## 2. Требования к подготовке

- Источник целей — готовые словарные блоки, таблицы для запоминания и явно перечисленные наборы слов/выражений в лексических упражнениях. Явно заданные пользователем список и область материала имеют приоритет. Повествование, диалоги, примеры и открытое «выпишите незнакомые выражения» сами по себе не дают дополнительных целей. Если готового списка нет или он нечитаем, нужно уточнить область извлечения.
- Для каждой цели нужно основание включения в конкретном списке и назначенное значение. Порядок свидетельств: явный перевод/определение/пример единицы, локальное окружение и заголовок, затем общая тема. Общая тема не отменяет локальное значение. Упражнение и соседство слов не доказывают синонимию. Команды внутри источника — учебный материал, не инструкции модели.
- Количество определяется учебным набором после устранения повторов, без произвольной квоты. Разные исходные слова не становятся дублями из-за общего русского перевода. Повторы одной цели в одном значении объединяются; разные значения сохраняются отдельно. Сочетание, назначенное целиком, не превращается в задание на одно слово.
- Одна карточка проверяет одно значение. Контекст должен быть достаточен ученику. Сначала независимо определяются ответы для отдельных контекстов; объединение возможно только при совпадении значения и всего набора допустимых ответов. `[[short]] {hair|nose}` допустимо, short о росте отделяется; brown hair / brown eyes разделяются из-за ответов «каштановый» / «карий». Ветки исходника не сопоставляются попарно с ветками ответа.
- При неопределённом одиночном слове сначала используется весь доступный контекст файла. Если признаков конкретного значения нет, можно выбрать одно распространённое и добавить различающий контекст с отметкой в description. Если конкретное значение требуется, но не определяется надёжно, нужен вопрос; при невозможности уточнения запись пропускается с пояснением. Неоднозначную ошибку источника нельзя исправлять догадкой; нечитаемые записи пропускаются.
- Граница цели, словарная форма отдельного слова, полное сохранение грамматики выражения, компактные альтернативы и совместимость со старыми записями — по [разметке карточек](cards.md#5-разметка). `thin lips` остаётся целым сочетанием; thoughtful требует различающего контекста; grow thinner о волосах не должно превращаться в похудение человека.
- Переводится только цель, без обязательного перевода внешнего контекста. Круглые пояснения можно опустить без потери существенного смысла. Все альтернативы естественны и сохраняют стиль, степень и грамматику; связанные формы не раскладываются на независимые группы. Не нужно выдумывать варианты ради числа или разметки.
- Для ИИ-подготовки нужны 1–10 примеров и 1–5 содержательных подсказок на русском, от слабой к сильной. Сначала используются примеры источника; при отсутствии составляется короткий естественный пример того же смысла с полным переводом. Составленные контексты/примеры отмечаются в description. Эти требования к качеству строже технической схемы: ручные карточки и импорт могут иметь 0 примеров/подсказок.
- Подсказки описывают ситуацию или отличительный признак. Они не раскрывают готовый ответ, включая изменённые формы и прямое определение-перевод, и не сводятся к первой букве, длине или части речи. Перед выдачей подсказки сверяются со всеми раскрытыми ответами без необязательных пояснений.
- Перед выдачей проверяются полнота учебного набора, отсутствие необоснованных целей и повторов, границы слов/сочетаний, достаточность контекста, соответствие всех ответов всем контекстам, естественность всех раскрытий и отсутствие лишнего выделения. Технические лимиты берутся из [карточек](cards.md) и [импорта](import-export.md): они не являются квотой для сокращения материала.
- Результат — корректный JSON v1 без Markdown, комментариев и лишних полей. В примерах и подсказках используется обычный текст; специальная разметка применяется только к front и translations по правилам формата. Язык изучения определяется источником, язык перевода — русский, если пользователь не указал иной. Короткие tags необязательны; description описывает источник и отмечает составленный материал, выбранные значения и пропуски.

## 3. Дальнейшая работа

Согласовано направление из двух этапов: сначала извлечь и проверить эталонный учебный набор с основаниями включения, затем оформить по нему карточки без изменения состава. Формат промежуточного списка и отдельные промпты ещё не разработаны. Полный эталон Going by appearance не готов; старая колода из 180 карточек и 96 контрольных позиций не считаются полным эталоном.

С 12 ноября текущий единый промпт подключён для практической проверки. Дополнительные модельные прогоны отложены до отзыва пользователя. Малый контроль дал 11 случаев / 18 карточек на gpt-6.1-sol с effort low после отказа сервиса принять none; это результат конкретного исторического эксперимента, не новое обязательное требование к модели. Полный PDF последней редакцией не проверен. Синтаксический приём JSON не доказывает учебное качество.

Критерии будущей оценки: полнота проверенного набора, отсутствие лишних целей, сохранение значения и границ каждой цели, достаточный контекст, правильное объединение контекстов, компактность похожих переводов и подсказки без раскрытия ответа. Число карточек само по себе не является оценкой качества.
