# Mnemo: колоды, карточки и разметка

Обновлено 18 ноября 2026. Действующие требования. Выбор обложек и навигация главной описаны в разделах 1 и 6.

Здесь определены данные, редактирование и синтаксис карточек (FR-D, FR-C). Проверку ответа и прогресс определяет [повторение](repetition.md). [Карта спецификаций](../../spec.md).

## 1. Колода (Deck)

| Поле | Тип | Обязательно | Примечание |
|---|---|---|---|
| id | UUID | да | |
| name | string (1..100) | да | уникально в рамках приложения (без учёта регистра) |
| description | string | нет | |
| source_language | string | нет | код (en, de, ...) или свободный текст |
| target_language | string | нет | |
| created_at, updated_at | datetime | да | |

Оформление хранится отдельно в `deck_appearance`, каскадно удаляется с колодой и не экспортируется в JSON v1. Новое требование — устойчивый идентификатор стандартного рисунка (`cover_id`): `cards`, `dialogue`, `route`, `book`, `spark` или `links`, по умолчанию `cards`. Цвет рисунка определяется общей палитрой приложения, отдельного пользовательского цвета колоды в новом интерфейсе нет. Большая «Спокойная стопка» на главной — общий ресурс, не значение `cover_id`.

Совместимость прежних записей «значок + цвет»: язык/автоматический значок → `cards`, книга → `book`, путешествия → `route`, работа → `links`; отсутствующий или неизвестный значок → `cards`. Прежний цвет не переопределяет общую схему; наличие старых полей не должно мешать загрузке. При обновлении не теряются карточки, названия или история. Новая/импортированная колода получает `cards`; обновление карточек в существующей колоде сохраняет её выбранный рисунок. Выбор рисунка хранится локально, исходные изображения пользователя не нужны. Внешний вид и меню выбора — [дизайн](design.md#85-стандартные-обложки).

## 2. Карточка (Card)

| Поле | Тип | Обязательно | Примечание |
|---|---|---|---|
| id | UUID | да | |
| deck_id | UUID | да | карточка принадлежит ровно одной колоде |
| front | string (1..500) | да | слово или фраза для перевода |
| translations | string[] (1..10) | да | один или несколько вариантов перевода |
| examples | Example[] (0..10) | нет | см. ниже |
| hints | string[] (0..5) | нет | упорядоченные: раскрываются по одной |
| tags | string[] | нет | опционально, для будущей фильтрации |
| created_at, updated_at | datetime | да | |

Example: `{ text: string, translation?: string }`.

CardState и ReviewLog описаны в [повторении](repetition.md#61-основной-прогресс-и-журнал). Заготовка входящего слова — отдельная сущность, см. [входящие](inbox.md). Примеры и подсказки необязательны для ручного ввода и импорта; требования к качеству ИИ-подготовки строже, см. [подготовку карточек](ai-preparation.md).

## 3. Управление колодами

- FR-D1. Создать колоду (имя обязательно, остальное нет).
- FR-D2. Переименовать / изменить описание.
- FR-D3. Удалить колоду. Требуется подтверждение с указанием числа карточек; удаляются карточки, их состояния и история.
- FR-D4. Список колод показывает: имя, число карточек, число карточек к повторению сегодня.

## 4. Управление карточками

- FR-C1. Создать карточку в выбранной колоде: поля из раздела 2, форма с динамическим добавлением переводов, примеров и подсказок.
- FR-C2. Просмотреть список карточек колоды с поиском по `front` и переводам.
- FR-C3. Редактировать любую карточку. Редактирование НЕ сбрасывает прогресс изучения.
- FR-C4. Удалить карточку (с подтверждением).
- FR-C5. Валидация: пустой `front` или пустой список переводов недопустимы; пустые строки в списках отбрасываются.
- FR-C6. При создании дубликата показывается предупреждение; создание всё равно возможно по подтверждению. Дубликат — совпадение ключа `front` в той же колоде после `casefold`, удаления пробелов по краям и схлопывания внутренних пробелов. Пробелы между словами не удаляются, разметка остаётся частью ключа.
- FR-C7. Возможность переместить карточку в другую колоду (желательно, не критично для v1).

## 5. Разметка

- В новых карточках `[[цель]]` используется только для отделения цели от содержательного внешнего контекста. Если вся строка — цель, она записывается без выделения: `thin lips`, `You look good for your age.`; пробелы и пунктуация снаружи не служат основанием для выделения. Старые записи с целиком выделенной целью продолжают приниматься и отображаться без изменения сохранённых данных. В `front` допускается один непустой участок `[[цель]]`: он выделяется жирным, контекст остаётся обычным. Без выделения переводится весь исходник. Для отдельного выделенного слова сессия просит словарную форму; пояснение уточняет мужской род единственного числа для прилагательного, инфинитив для глагола и именительный падеж для существительного. Выделенное выражение переводится целиком.
- `{a|b}` в исходнике задаёт альтернативные контексты вне выделенной цели; для такой группы обязательно выделение цели. Все контексты видны одновременно, с границами `[a / b]`, без случайного переключения. Например, `[[short]] {hair|nose}` показывает жирное short и обычное `[hair / nose]`. В `translations` группа сокращает только отличающиеся части похожих ответов: значимая общая часть пишется один раз снаружи. На обороте обрамляющие скобки скрыты: `Выглядеть старше {своих лет|своего возраста}` → `Выглядеть старше своих лет / своего возраста`. Самостоятельные ответы без общей части, например «стройный» и «подтянутый», записываются отдельными строками translations. Старые группы из полных ответов продолжают приниматься и показываются через / без скобок; данные автоматически не переписываются.
- В переводе раскрываются все сочетания независимых групп с сохранением общего текста: `выглядеть {молодо|хорошо}` принимает «выглядеть молодо» или «выглядеть хорошо». Вложенные группы и пустые ветки запрещены; каждая группа содержит минимум две ветки. Связанные формы без сокращаемой общей части записываются отдельными строками, например «Он пришёл» и «Она пришла»; прежние целые ветки также поддерживаются. К каждому раскрытому ответу применяются FR-S10, FR-S11 и FR-S14; шаблон `{…|…}` не является вводимым ответом.
- Круглые скобки в переводах остаются пояснением: принимается полный ответ с пояснением или ответ без всех пояснений. Скобки в исходнике помогают выбрать смысл. Их содержимое не становится отдельной целью.
- Синтаксическая проверка редактора и импортёра отклоняет незакрытую/вложенную разметку, пустые ветки, несколько выделений и выделение в переводе. Технический предел — 256 раскрытых сочетаний на одну строку, включая группы контекста. Это не квота карточек. Одинарные `[` и `]` — обычный текст; буквальный ввод зарезервированных `[[`, `]]`, `{`, `}` в новых карточках не предусмотрен. Старые некорректные записи показываются и сравниваются буквально, без частичного раскрытия; для пересохранения требуется исправить разметку.
- Данные в SQLite, редакторе и JSON-экспорте сохраняются без удаления разметки; версия JSON остаётся 1. Сессия, список карточек, статистика и предпросмотр импорта используют читаемое представление; отображение не меняет сохранённую цель и ключ дубликатов. Произвольный HTML из карточек не интерпретируется как оформление цели.

Правила нового оформления относятся к автору карточки и промпту. Синтаксический валидатор не проверяет педагогическое качество: ради совместимости он принимает полное выделение цели и группы из целых ответов. Это не рекомендация создавать такие новые записи. Числовой предел раскрытия и лимиты полей остаются обязательными.

## 6. Сценарии управления

**Навигация.** При обычном ручном запуске приложение открывается на экране «Колоды»; автозапуск в трей описан в [FR-Q2](inbox.md#2-поведение). Оттуда: «Учить колоду» в блоке выбранной колоды и «Начать повторение» справа запускают сессию (FR-S1) для выбранной или всех колод соответственно; одиночный щелчок по нижней миниатюре выбирает колоду, двойной открывает её с сохранением прежнего выбора. Страницу выбранной колоды также открывают название-ссылка в крупном блоке и «⋯ → Открыть». «Создать колоду», «Импорт», «Статистика», «Входящие» доступны в верхней строке. С экрана колоды: «Учить (n)», «Повторить всю колоду», «Добавить карточку», иконки изменения и удаления слов, «← К колодам» и шестерёнка настроек (название, обложка, импорт, экспорт, удаление). Завершение с подтверждёнными попытками открывает итоги; выход из итогов возвращает на исходный экран. Без попыток завершение сразу возвращает назад.

**Экран «Колоды» (FR-D1–D4).**
- Блок «Сегодня к повторению»: суммарное число карточек к повторению по всем колодам и число колод, в которых они есть; кнопка «Начать повторение» и вход «Свободное повторение».
- Нижняя горизонтальная лента: выбранная контурная миниатюра, название, общее число карточек и число к повторению; состояния пустой колоды и «Всё повторено» различимы. Выбор обновляет крупный блок с общей обложкой, названием, языками, числом карточек, «Учить колоду», «Повторить» и меню ⋯ (открыть, переименовать, обложка, экспорт, удалить). Учебное действие отключено при пустой основной очереди; свободное повторение доступно у непустой колоды. Порядок, выбор и доступ к скрытым элементам ленты — в разделе 8 дизайна.
- Удаление колоды: подтверждение с названием и числом карточек (FR-D3).
- Первый запуск (колод нет): сообщение «Колод пока нет» и действия «Создать колоду» и «Импортировать».
- Создание колоды: небольшое окно с полями «название» (обязательно, уникально без учёта регистра), «описание», «язык слов», «язык переводов»; после создания открывается пустая колода.

**Экран колоды (FR-C2, FR-C4).**
- Под метаданными колоды — отдельное действие «Повторить всю колоду» (FR-S15), доступное при наличии хотя бы одной карточки, независимо от числа к повторению сегодня.
- Заголовок с названием, строка «N карточек · языки · M к повторению».
- Поиск по слову и переводам, срабатывает при вводе; если ничего не найдено, показывается «Ничего не найдено».
- Список карточек: слово, переводы, статус («новая», «учится», «выучена»), иконки карандаша и корзины с подсказками (удаление с подтверждением). Над списком — заголовки «Слово», «Перевод», «Статус».
- Пустая колода: сообщение и действия «Добавить карточку» и «Импорт в колоду».

**Редактор карточки (FR-C1, FR-C3, FR-C5, FR-C6).**
- Отдельный экран: слово, переводы (несколько), примеры (оригинал и перевод), подсказки (упорядоченные); поля добавляются кнопками «+ Добавить…» до лимитов из раздела 2.
- «Сохранить» возвращает в колоду; «Сохранить и добавить ещё» сохраняет карточку, очищает форму и возвращает фокус в поле слова; «Отмена» возвращает без сохранения, при несохранённых изменениях спрашивает подтверждение.
- Ошибки валидации показываются рядом с полем; предупреждение о дубликате показывается под полем слова, сохранение возможно по повторному нажатию.
- Правка не сбрасывает прогресс изучения (FR-C3).

Статус в списке определяется по [правилам повторения](repetition.md#55-трудность-порядок-и-статусы). Компоновка и размеры — [дизайн](design.md#8-экран-колоды-главный).

## 7. Критерии приёмки

- Пользователь создаёт колоду и 3 карточки, закрывает и открывает приложение, данные на месте.
- Правка перевода сохраняет `reps`, `ease` и историю карточки.
- Удаление колоды удаляет все связанные записи (проверяется по базе).
